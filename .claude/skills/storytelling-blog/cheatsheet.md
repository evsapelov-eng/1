# Шпаргалка: если X, делай Y

## Цель и тема

- Есть тема, но нет цели → сформулируй «хочу, чтобы читатель поверил, что …». Не получается сформулировать, значит, поста пока нет.
- Цель звучит как «рассказать о …» → перепиши через веру или действие.
- История обо мне, пользы читателю нет → найди зерно пользы или не пиши.

## Начало

- Первая строка объясняет, что сейчас будет → удали, начни с действия.
- История начинается с экспозиции («Я давно думал о…») → найди первый момент действия и начни с него.
- Нужно оправдать, зачем слушать → одна фраза-разрешение: «Расскажу случай, который показал мне…».
- Хук общий («Случилась дичь», «Сегодня понял важное») → замени конкретикой: время, предмет, цифра.

## Середина

- Нет напряжения и перемены → это отчёт. Найди, что удивило, сломалось, пошло не так.
- Мысль про «казалось, оказалось» → поставь ожидание и поворот рядом, коротко.
- Много деталей → оставь две-три, самые ощутимые.
- Нет деталей → спроси автора об одной настоящей. Не выдумывай.
- Хочется вставить больше фактов → вставь, но две-три цифры на ролик, не десять.
- Нужно вспомнить эмоцию → пиши ту, что автор правда пережил, без «был в восторге» из воздуха.

## Конец

- Финал мораль в лоб («главное, друзья, ценить момент») → замени выводом из поступка или фактом.
- Личный пост → заверши открытым вопросом аудитории.
- Новость или комментарий → заверши широким наблюдением, без вопроса.
- Финал «будущее выглядит многообещающим» → замени конкретным планом или удали.

## Длина

- Ролик на 20 секунд → около 45 слов. На 30 секунд → около 65.
- История длиннее минуты → режь на серию.
- Две темы в одной сторис → раздели.
- Короткий пост выглядит бедным → не добавляй воды, добавь одну деталь.

## Серии

- Одна история на тему → мало, это «случайность». Планируй 3–5 историй вокруг одной мысли.
- Серия однотипна → чередуй: история, факт, новость, вопрос.
- Хочется закончить открытой петлёй → пообещай продолжение только если оно действительно будет.

## Тон

- Звучит как пресс-релиз → добавь первое лицо, мнение, неровность.
- Звучит как нейросеть → прогони по анти-AI чеклисту из `voice-modes.md`, потом по скиллу `pishi-sokraschay`.
- Хочется метафору про профессию автора → не нужно, пока он сам не попросит.
- Хочется драмы, которой нет в фактах → убери слово, не усиливай.

## Промо и анонсы

- Хочется пересказать, что происходит на событии → не пересказывай, спойлер подрывает продажу.
- Хочется вставить цитаты зрителей → не вставляй, если автор не просил.
- Хочется написать «зал был полный» → вычеркни.
- Фраза «рассказывать не будем» → вычеркни, просто не пиши о деталях.
- Нужен призыв → простой и конкретный: где слушать, где следить за анонсами.

## Перед отправкой

- Есть сомнения в написании имени, фамилии, названия → спроси автора.
- Нужно убрать рискованную личную подробность из публичного текста → убери и скажи одной строкой.
- Автор продиктовал формулировку → сохрани её слова, правь только ошибки и повторы.
- Читаешь вслух и спотыкаешься → перепиши фразу.
